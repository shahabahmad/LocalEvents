# LocalEvents

This application is using clean architecture.
We have presentation layer, domain layer, use cases, data layer and infrastructure layer.
This application includes disk image caching, in memory url data caching
I have used app factory to inject dependencies.
This appication is fully protocol oriented.
There is a lot of room for unit testing. 
I have used core data to store bookmarks and latest events.
I dont keep book mark for those event which is no more available.
All the code and files are organised as per the clean architecture standard.
